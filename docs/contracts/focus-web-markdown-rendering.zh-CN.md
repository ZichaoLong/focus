# Focus Web Markdown 正文渲染合同

文档角色：中文规范源。英文同步副本：`docs/contracts/focus-web-markdown-rendering.md`。

## 正文强调与换行

`web/src/lib/markdownParser.ts` 的 `configureFocusMarkdown` 是聊天与问答打印页的共享
解析配置入口；公式语法仍由 `markdownMath.ts` 持有，复制行为见
[Markdown 复制合同](focus-web-markdown-copy.zh-CN.md)。

双星号加粗在紧邻中日韩文字时，允许加粗范围内的标点参与边界识别，例如
`**结论。**后续` 和 `这里**“重点”**继续`。定界符仍由 Markdown 解析器配对；
不通过改写整份源码、插入空格或补换行来修复展示。其他强调语法沿用原解析规则。
代码、转义、链接地址与已识别公式内部的星号不得因此成为正文加粗。
规则同时适用于流式输出与加载的历史回答，打印页复用同一强调规则。

聊天正文保留普通换行、显式硬换行与空行分段；代码保留原始行与缩进。
加粗句子后若源码没有换行，不自动变成独立标题或新段落。

聊天 Markdown 与打印正文允许浏览器在缺少真实粗体字形时合成粗体，保持中文强调
可见，但不启用斜体合成或改变应用其他界面的字体策略。不同设备的字体外观不保证
像素一致。上述展示规则不修改保存的消息、复制源码或导出 Markdown。

## 验证边界

回归覆盖中文标点、嵌套行内语法、列表与表格、代码与转义、公式、流式到最终状态、
换行与打印页。浏览器验证使用真实 Markdown 组件，检查宽窄视口中的加粗、字体回退、
段落与代码换行；模拟窄屏不等于验证所有真机字体。
