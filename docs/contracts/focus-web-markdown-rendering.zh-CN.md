# Focus Web Markdown 正文渲染合同

文档角色：中文规范源。英文同步副本：`docs/contracts/focus-web-markdown-rendering.md`。

## 正文强调与换行

`web/src/lib/markdownParser.ts` 的 `configureFocusMarkdown` 是聊天与问答打印页的共享
解析配置入口；公式语法仍由 `markdownMath.ts` 持有，复制行为见
[Markdown 复制合同](focus-web-markdown-copy.zh-CN.md)。

双星号加粗在紧邻中日韩文字时，允许加粗范围内的标点参与边界识别，例如
`**结论。**后续` 和 `这里**“重点”**继续`。若内侧是中日韩专用／全角标点，或标点串
内侧紧邻中日韩文字，也允许外侧紧接字母或数字，例如 `**结论。**Mamba`、
`RoPE**（局部）**2` 和 `2026**“中文”**Next`。纯英文共享引号与标点沿用原规则。
定界符仍由 Markdown 解析器配对；
不通过改写整份源码、插入空格或补换行来修复展示。其他强调语法沿用原解析规则。
代码、转义、链接地址与已识别公式内部的星号不得因此成为正文加粗。
规则同时适用于流式输出与加载的历史回答，打印页复用同一强调规则。

聊天正文保留普通换行、显式硬换行与空行分段；代码保留原始行与缩进。
加粗句子后若源码没有换行，不自动变成独立标题或新段落。

表格单元格中的文字、行内公式、强调、链接和行内代码保持连续排版，不因长回复
渲染优化或行内节点边界插入换行、段落间距。段落间距不施加于单元格内的行内
片段；单元格仍可按可用宽度自然折行，宽表格继续在自己的容器内横向滚动。

表格分列须保护同一行完整闭合的 `\(...\)` 公式，公式内部的竖线不得成为列分隔符，
也不得导致后续单元格内容丢失。规则覆盖表头、正文、嵌套表格和流式闭合后的内容，
聊天与打印共用。识别沿用公式语法入口；代码、转义的定界符、未闭合内容及不支持的
公式写法不因此变成公式。公式原有竖线、反斜杠和空白须保留到源码回退与公式复制，
不以替换 LaTeX 命令或改写保存内容来修复表格。

聊天 Markdown 与打印正文允许浏览器在缺少真实粗体字形时合成粗体，保持中文强调
可见，但不启用斜体合成或改变应用其他界面的字体策略。不同设备的字体外观不保证
像素一致。上述展示规则不修改保存的消息、复制源码或导出 Markdown。

正文随页完整加载与长回复展示遵循[有界正文窗口合同](focus-web-transcript-window.zh-CN.md#回复时间与长回复)。
`markdownChunks` 使用同一解析配置解析完整文档后分组，保留跨组引用上下文与完整的
表格、列表、公式和代码块。长回复 diff fence 的原始增删行全部可通过滚动读取，不使用
普通 diff 预览的 head/tail 省略；全文复制仍来自完整源字符串。

## 验证边界

回归覆盖中文标点与中日韩／英文／数字相邻的边界、嵌套行内语法、列表与表格、代码与转义、
公式、流式到最终状态、换行与打印页。浏览器验证使用真实 Markdown 组件，检查宽窄视口中的加粗、字体回退、
段落与代码换行，以及启用长回复渲染优化后的表格行内混排与横向滚动；
同时检查含竖线公式的完整列内容、复制源码、流式闭合与打印回退；
模拟窄屏不等于验证所有真机字体。
