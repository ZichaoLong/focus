# Focus Web 单文件下载与预览

文档角色：中文规范源。英文同步副本：`docs/contracts/focus-web-file-download.md`。

## 访问与文件内容

已认证的 Focus Web session 可以下载 Focus 服务进程能够读取的普通文件。这里沿用实例的
完全信任协作者模型，不增加工作区白名单、逐文件审批或用户 ACL。工作区仅用于解释相对路径。
符号链接可解析到工作区外；目录、设备、管道等非普通文件不提供下载。此功能不提供目录树、
文件编辑或压缩打包。文件预览只在浏览器收到明确查看操作后读取同一文件接口。

- `GET /api/files/info?path=...&cwd=...` 校验路径、文件类型和可读性，返回 exact
  `FocusFileInfo={path,name,size}`，其中 path 为解析后的服务器绝对路径、name 为文件名、size 为
  非负字节数。仅检查元数据和打开权限，不读取正文。相对路径需要绝对 cwd；`~` 按服务端账号展开。
- `GET /api/files/download?path=...&filename=...` 接受绝对路径，可选 filename 仅建议客户端保存名。
  不需要浏览器 document 或 writer authority，因此普通浏览器下载可以使用 session cookie，
  不把 token 放进 URL。两个 endpoint 都经过既有 Host、session、trusted-proxy audience 准入，
  不续期 session，不调用 app-server 或 RuntimeLoop。
- 两条 query 拒绝未知、重复字段、空 path 与 NUL。文件缺失、不可读、非普通文件或无法解析
  分别显式失败。失败响应不携 attachment header。
- 文件传输使用 `application/octet-stream`、`Content-Disposition: attachment`、`Cache-Control: no-store`。
  基于已有 aiohttp FileResponse 的有界文件传输与 HTTP Range 行为，禁用静态资产的同名 `.gz/.br`
  替换，服务端与下载流程不缓存整个文件，不增加运行依赖。预览在浏览器按下述上限有界读取。
- 下载取得本次读取的文件，不是回复生成时的历史副本。信息查询与下载之间可发生文件变动；
  下载重新校验文件。正在原地写入的文件不提供快照一致性，HTTP Range 也不保证跨版本续传。

## 链接与保存体验

`Markdown.vue` 的本地链接委托给 Focus 文件下载弹窗；外部 URL 和 Mermaid SVG 内的链接保持
原语义。显式 Markdown 链接在流式输出时也可点击；普通文本中的自动路径识别仍等待输出稳定。
本地 URI／百分号编码、绝对／相对路径与常见行号引用被转换为文件路径，行号不成为文件名。
相对路径的 cwd 来自打开链接时的会话；网络等待和后续切换会话不能重定向下载目标。
本地图片引用同样显示显式文件下载链接，不自动读取或嵌入图片；未提供文件操作回调的消费者
仍保留原有不可用提示。

点击链接只加载文件信息。弹窗显示服务器路径、大小、可编辑的保存文件名与实际保存名称，
按浏览器能力显示“另存为”或“下载”；关闭弹窗取消页面拥有的请求和写入。

- 系统保存窗口复用 `browserFileSave.ts`，在确认手势内、正文读取前调用 `showSaveFilePicker`。
  用户取消即结束。调用因 SecurityError／NotSupportedError 不可用时，改为明确显示普通下载说明，
  需要用户再次点击，不自动另下载一份。
- 原生保存按响应流分块写入，展示已接收字节数，写入和关闭均成功才提示保存完成。取消或失败
  尝试 abort staged writes，不回退为另一份下载；不自动删除用户选中的文件。系统窗口可能已创建空文件。
- 不支持系统保存窗口时，点击下载先复查文件可用性，再交给浏览器原生下载管理，避免完整 Blob。
  保存目录遵循浏览器设置；Focus 只提示“已交给浏览器”，不声称文件已保存。交接后的进度／取消由
  浏览器拥有。错误若发生在复查之后，由浏览器处理，错误页在独立标签页中，不替换会话。
- 原生写入并关闭成功，或普通下载已交给浏览器后，自动关闭下载弹窗并显示短暂状态提示；
  后者不声称下载完成。失败或用户取消保留弹窗以便重试。从预览发起下载时，完成或取消后回到
  原预览，保留其内容和滚动位置，不重复请求预览。
- 路径、句柄和下载状态不持久化；不存在自动预取正文或自动预览。保存文件名按可移植字符与
  UTF-8 字节预算处理，保留文件扩展名，不修改服务器文件。

既有 Markdown／JSONL 导出只复用系统保存窗口的选择规则，继续按
[导出文件名合同](focus-web-export-filenames.zh-CN.md)保持完整 Blob、命名、独立文档标题、取消
与回退行为；PDF 打印流程不变。

## 按需预览

下载弹窗提供独立的预览入口。打开文件链接只获取元数据，不自动读取正文；加载会话、经过链接
或打开文件信息不会预取。预览复用同一个 session-authenticated 文件传输接口；HTML 的隔离引导页
见下节。页面同时只保留一个预览，不持久化文件内容或对象 URL，不增加服务端运行依赖或独立服务。

- `filePreview.ts` 拥有预览请求、取消、完整内容与对象 URL 的生命周期；关闭、替换或刷新预览
  会取消旧请求并释放旧内容。刷新只由用户发起，获取当前文件，不提供历史快照或自动追踪。
- 文本／代码／日志／JSON 等保留完整可选、可复制的只读源码，可切换自动换行。支持严格
  UTF-8 与带 BOM 的 UTF-16，未知类型、二进制或不支持的编码明确提示下载，不以替换字符冒充原文。
  文本上限 1 MiB；元数据、响应 Content-Length 与实际流字节数分别检查，防止文件变大突破上限。
  超限显示明确提示，不显示貌似完整的截断正文；不改变会话正文的分页或显示规则。
- Markdown 在 128 KiB 内默认渲染并可切换源码，以上至文本上限显示完整源码并明确说明。
  行号链接默认定位源码对应行；超出行数定位末行。相对链接按被预览文件的解析后目录解释，
  不使用随后切换的会话 cwd。共享 Markdown 的公式、表格、代码与 Mermaid 能力，但采用隔离
  parser 配置：图片（包括引用式图片）转为显式链接，原始 HTML 按文本显示，不发起附件请求；
  会话和打印的 Markdown 行为不变。
- 本地链接保留章节 fragment，`#2-章节` 不解释为第 2 行。渲染 Markdown 时匹配标题 ID 或常见
  小写连字符 slug 并滚动定位；未找到则明确提示，源码视图仍在文件信息中保留目标章节。
- 图片支持 PNG／JPEG／WebP／GIF／BMP／ICO／静态 AVIF，读取原文件，不提供缩略图或转码。传输上限 16 MiB；
  `filePreviewImage.ts` 在创建 Blob URL、交给浏览器解码之前检查格式头：最多 2400 万像素，
  任一边不超过 32768 像素。损坏／不支持的图片显式失败，仍可下载。
- GIF 保留动画，额外限制为 1000 帧及逻辑画布像素数乘帧数不超过 9600 万；AVIF 序列暂不支持。
  ICO 检查目录和实际图像尺寸，AVIF 检查主图关联及各图像属性，不能只信任小尺寸的外层声明。
- SVG 使用文本上限，检查 XML 根元素与尺寸，拒绝自定义实体。只通过 Blob 图片显示，保留源码
  切换，不插入主文档 DOM，不执行 SVG 脚本或加载外部资源。尺寸沿用图片上限；无显式尺寸时
  使用 viewBox／宽高比，均缺失时使用 300×150。格式或尺寸失败时保留完整源码。
- CSV／TSV 默认显示分页表格，每页 50 行。引号、转义引号、多行单元格、空值和不齐的行按原文
  解析，第一行也是数据，不猜测标题或转换数值／日期，不执行公式。最多 200 列、10 万单元格；
  无效引号或超过结构上限时明确退回完整源码。
- JSON／JSONL／NDJSON／ipynb 默认显示可折叠树，保留键顺序、重复键和数字原始写法，避免大整数
  舍入。JSONL 按行独立校验并保留行号。最多 1 万节点、64 层，单节点的子项每页 100 项；格式
  错误或超限时保留完整源码。空 JSONL 可显示空集合。
- 常见代码和配置文件按文件名识别语言，按需加载 Shiki 的 JavaScript 正则引擎；少于 3 万字符时
  默认高亮，超限保留完整源码。代码按 token 文本展示，不作为 HTML 或 Markdown 解释。
  独立 `.mmd/.mermaid` 在 32 KiB 内复用现有严格 Mermaid 渲染和查看器；其合成 Markdown 围栏
  必须长于源码内所有反引号串，源码不能逃逸成其他 Markdown。两者均可切换源码；代码高亮加载
  失败明确保留全文，Mermaid 加载／语法失败沿用共享渲染器的可读源码回退。
- `ImageViewport.vue` 为图片和 Mermaid 共用适应整图、100%、放大缩小、拖动与双指缩放交互；
  普通照片使用浏览器按 EXIF 方向解码后的尺寸。查看器不会改动服务器文件。
- 桌面默认预览宽度最多 1120px，高度随可见页面增长并保留外边距。所有文件类型共用“最大化
  预览／还原预览窗口”，最大化铺满页面可用区域，保留浏览器界面，不调用浏览器全屏 API。
  窄屏继续自动铺满页面，不显示重复的最大化按钮。Markdown 正文限制阅读行宽；独立表格、
  代码、图片等使用可用宽度。HTML 原有浏览器全屏入口独立保留。
- `FocusFileDownloadDialog.vue` 持有本次预览的最大化选择；沿文件链接前进、取消和后退时保留，
  结束整次预览或从会话打开新文件时重置。文件信息与下载窗口仍使用普通尺寸，关闭／取消行为
  不变。尺寸切换不重新读取文件、不重建渲染器，保留 PDF 页码、手动缩放、表格页码、展开状态
  和 HTML 内部状态；适应整图／整页模式随尺寸调整。滚动和源码选区保留，接近末尾时滚动位置
  可能受新尺寸限制。返回另一文件仍按“预览内后退”规则重新读取。
- 关闭恢复原会话焦点与滚动位置。预览中保留下载和刷新入口，下载的文件名编辑及系统“另存为”
  行为保持不变。嵌套 Mermaid 查看层关闭不同时关闭文件预览。
- 预览顶部共用单行工具栏，提供关闭、可收缩的文件名、下载、Markdown／HTML 源码／渲染切换、正文
  复制和刷新；SVG、结构化数据、代码及 Mermaid 也复用源码／渲染切换。图标操作具备文字标签，
  触摸目标为 44px。长文件名中间省略，保留首尾；点按文件名
  打开独立滚动的浮层，完整显示并允许分别复制文件名与服务器路径。桌面悬停也显示完整文件名。
  再次点按文件名、点按浮层外或 Esc 关闭浮层，不挤压正文、不改变其滚动位置；Esc 只关闭当前层。
  不自动刷新等说明、源码自动换行开关和图片手势帮助均收进浮层；图片缩放操作仍可直接使用。
  大 Markdown 仅显示源码时保留紧凑源码标记，原因可在浮层查看；定位行号和复制结果仅作短暂提示。

Office、音视频暂不提供内嵌预览；原有导出 PDF 的打印流程不受影响。

## 预览内后退

`filePreviewNavigation.ts` 拥有本次文件预览的导航记录，编排既有下载和预览 owner；不保留第二份
文件内容或请求状态。从 Markdown／HTML 的本地文件链接进入另一文件时，记录原文件的已解析
绝对路径、行号／章节目标及轻量阅读状态。最多保留最近 20 步；不持久化，不写入浏览器历史或 URL。

- 有历史时，预览工具栏提供“返回上一文件”。文件信息窗口统一提供“取消”：从会话首次打开时
  关闭窗口；从预览中的链接打开时，放弃本次操作并直接回到上一份预览，无需再次点击“预览”。
  读取中、失败、类型不支持或大小超限时同样可取消返回。
- 返回重新获取元数据和当前文件内容，继续执行大小与格式检查；它不是历史内容快照。
  Markdown／源码视图尝试恢复原滚动位置、源码模式和换行设置。布局异步变化时短暂跟随恢复，
  用户开始滚动、触摸或键盘操作后停止调整；文件内容或窗口尺寸变化可能使位置不同。
- HTML 返回时重新创建隔离页面并执行源码，不保留其内部表单、脚本状态或内部滚动位置。
  离开的文档、Blob URL、iframe 和 PDF worker 按既有生命周期释放，不叠加后台预览。
- 工具栏“关闭预览”及文件信息窗口的关闭按钮结束整条预览并清空历史；从会话打开另一个文件
  也开始新记录。下载表单覆盖当前预览时不增加历史，取消／完成仍返回原预览；工具栏文件信息
  浮层与 Mermaid 放大层仍各自关闭，不当作文件导航步骤。
- 连续后退、打开新文件或关闭会取消被替代的读取；晚到的元数据或内容不能重新打开旧目标。
  手机系统返回键、浏览器返回／前进及手势维持浏览器原有行为，单独设计其集成。

## PDF 预览

PDF 使用同一下载接口有界读取，独立上限 32 MiB，元数据、Content-Length 和实际读取均受限。
只有显式打开 PDF 预览才加载固定版本的 `pdfjs-dist`，在本地 worker 中解析；不使用浏览器内置
PDF 插件、`object` 或附件 URL iframe。每次显示一页，提供翻页／页码输入、适应整页、缩放和
可选择文字层；扫描页不做 OCR。文字层超过每页 1 万项或提取失败时保留页面并明确提示。
Canvas 最多 1200 万像素、单边 8192 像素，DPR 最多 2；页内解码图片也有 2400 万像素上限。

密码仅交给当前 PDF loading task，不保存；错误密码可重试，关闭取消等待。切页／缩放取消旧渲染，
关闭、替换或刷新销毁 loading task、worker 和 Canvas；下载弹窗覆盖预览时保留当前页和缩放。
损坏、不支持或运行库加载失败时明确提示，下载／关闭／刷新仍可用，不展示貌似完整的部分页面。
不启用 PDF JavaScript、XFA、交互表单、链接或附件操作，普通注释的静态外观可绘入页面。

PDF.js 主模块和 worker 按需加载；CMaps、标准字体及无 Wasm 的 JPEG 2000／JBIG2 解码资源随
构建以版本化路径自托管，许可文本进入第三方清单。使用 `useWasm:false` 的解码／函数解释路径，
保持主应用 CSP，不增加 `unsafe-eval` 或 `wasm-unsafe-eval`；不启用 Wasm ICC 色彩管理。
服务部署和安装仍只需要现有 Python 包与静态资源，不需要 Node/npm、原生 Canvas、系统 PDF
工具、CDN 或新增端口。只有源码构建需要锁定的 npm 依赖及符合 PDF.js engines 的 Node 版本。
安装包与首次 PDF 查看资源下载会增大，解析和绘制消耗客户端 CPU／内存；客户端需要 PDF.js
支持的现代浏览器，功能缺失时可下载原文件，不要求用户安装插件。

## HTML 交互预览

`.html/.htm` 支持自包含报告、图表和演示：HTML、CSS、JavaScript、SVG、图片与数据应内嵌。
HTML 独立上限为 8 MiB，元数据、Content-Length 和实际读取均受限；解码沿用严格 UTF-8／带 BOM 的
UTF-16。浏览器只读取一次文件，源码与渲染共用完整内容。显式刷新重新读取；切回渲染重新执行页面。

`GET /api/files/html-preview` 是无 query 的固定引导文档，经既有 Host、session、trusted-proxy audience
准入，不续期 session、不注册 active document、不调用 RuntimeLoop，也不读取用户文件。它复用现有
Web 服务和端口，没有新进程、目录映射、内容缓存或 token URL。wire v35 要求服务与静态资源同步部署。

只有该 endpoint 的成功响应采用专用 CSP：`sandbox allow-scripts`，不授予 `allow-same-origin`；
只允许内联脚本／样式和 data/blob 媒体，禁止网络资源、connect、worker、嵌套 frame、object、base 和表单提交。
`frame-ancestors 'self'` 允许 Focus 嵌入；其他响应不获得该例外。主应用 CSP 保持原样。
iframe 显式委派 fullscreen，支持报告自身和 Focus 工具栏的用户触发全屏；浏览器不支持时明确提示。

`FocusHtmlPreview.vue` 只向 exact iframe 一次性交付内容和私有 MessagePort。引导代码先验证 parent 与
origin，持有 port 的闭包，再安装原始文档。报告脚本没有父页面、Cookie、存储或 Focus API 的同源权限。
正文的链接仅在真实用户点击后经闭包 port 交回 Focus；普通 `window.postMessage`、脚本 `.click()`
和已卸载页面不能发起文件打开。窗口消息不运输文件读取结果。

本地出处沿用现有文件弹窗，按当前报告解析后的目录定位，保留行号／章节，不使用后来选择的会话 cwd。
点击先读元数据，再由用户选择预览或下载；不预取引用。页内 `#fragment` 留在报告内。外部链接明确提示
不支持，不通过沙箱弹窗打开。外部资源被 CSP 阻止、脚本出错或引导失败时显示附注，源码与下载仍可用。

关闭、替换、刷新或转入源码会卸载 iframe 并关闭消息通道。下载弹窗暂时覆盖预览时保留其状态；
从 Focus 工具栏全屏进入下载前先退出全屏，避免弹窗被原全屏元素遮挡。
不承诺跨刷新恢复报告的内部状态；沙箱隔离权限，不提供 CPU／内存配额。字体、全屏和触摸行为取决于客户端
