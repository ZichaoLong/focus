# Focus 移动容器

文档角色：中文规范源。英文同步副本：`docs/contracts/focus-mobile.md`。

## 入口与认证

每个入口保存名称、站点 origin、随机实例 ID 和可选的网页登录方式。每次只选中一个实例，只有选中的实例维持业务订阅。
远端根地址从系统信任的 TLS 链加载。本地 Focus 授权另接受手机回环 HTTP（仅 `localhost`、`127.0.0.1`、`[::1]`），Basic 凭据仅在 HTTPS 上使用。原生 Basic 认证使用单独的无脚本顶层 GET `/focus-connect.txt`，
阻止子资源及重定向携带新凭据。只有配置的 HTTPS 站点和实际挑战的 Basic realm 均匹配才响应。
浏览器引擎在同一保护空间内处理随后请求和 WebSocket Upgrade。重试失败须由用户更新，超时保留原凭据。
本版支持整个入口共用 Basic 保护空间。页面运行期间遇到新的挑战时可以重新验证入口。
Focus 的 cookie、注册、可信代理证明和 mutation admission 继续遵循外部访问和 wire 合同。

## 宿主协议 v1

入口的 `focusApp` 查询参数只让根页面短暂等待协商。原生在配置 origin 的顶层根文档检测
`meta[name=focus-mobile-contract][content="1"]`，注入本 document 的随机 ticket、实例 ID、版本和能力列表，
并发送 `focus-host-ready`。未知版本和无协商的页面使用浏览器默认行为。

- `wake` 表示可接收 `focus-host-resume` 和 `focus-host-pause`。前台信号触发现有连接检查，后台信号刷新草稿与阅读锚点。
- `thread` 允许根页面通过带 ticket 的 `thread` 操作提交最近的线程定位提示（至多 256 个字符，空串表示工作区）。壳在下次打开时把它编码为根页面的 `thread` 查询参数，Web 仍须经现有入口向服务端确认该线程。
- `resume` 表示整个实例只有一个可恢复的浏览窗口。Web 保存 client hint、GET locator、原 writer 的恢复记录、最近一次已确认的线程、文字草稿及最近已确认线程的阅读模式与位置。
  新 document 必须重新注册。文字和可验证阅读锚点按实例及当前已确认的线程或工作区恢复，附件、审批 capability 与发送 scope 仍属于服务端签发的 writer。
  已协商恢复的 Web 页面在可用时用按实例隔离的 IndexedDB 严格持久事务记录文字草稿、模式和阅读锚点，初始化时迁移本地旧记录，清理草稿同步删除持久副本。请求记录及附件凭据沿用各自原有存储。
- `tabs` 提供可选的显示名 `name`。根页面使用带 ticket 的 `instances` 打开实例列表，用 `chrome(web|native)` 指示实例入口是否已由网页呈现。切换时由目标页面直接占用可用空间。若短暂等待后网页仍未提供入口，宿主显示紧凑的「切换实例」按钮。宿主发现连接或认证错误、或收到 `chrome(native)` 时立即提供该按钮；收到 `chrome(web)` 时取消等待并收起按钮。
  切走时宿主在顶层调用 `__focusSetTabActive(false)`。Web 刷新草稿和阅读锚点、关闭 socket 并停用轮询和重试。只有收到 `true` 才可保留该文档。管理实例可设置最近保留 1 至 5 页，默认 2 页，含当前页，每实例一页。超出上限或调低设置时先释放最久未使用的页面。回到实例调用 `__focusSetTabActive(true)`，经原有握手和状态重读恢复。无确认、内存回收及手动重新连接均可重建页面。
- `save` 使用 `prompt("focus/1/<ticket>/<op>", value)` 在两个引擎内等待系统选择或写入结果。
  `choose` 只接受文件名，系统选择目标。`write` 携带最多 24 KiB 原始字节的 Base64，逐块确认后发下一块。
  `finish` 从临时文件写入选定目标，`abort` 释放暂存。成功返回 `ok`，取消或失败使 Web 停止写入。
  正文由现有带会话的 Web 请求读取。普通 HTML 上传沿用系统文件选择器和原 Web 上传路径。
- `print` 接收一次带 ticket 的打印请求及不超过 255 字符的任务名。Web 只呈现已准备好的完整问答打印预览，原生把当前网页交给系统打印面板。Android 仅在系统返回打印任务时回报成功。创建失败时，预览显示错误并保留正文供重试。正文留在当前 document 的内存中。
- `navigation` 让已协商的顶层文档把用户实际点击的跨站 HTTPS 内容链接交给带 ticket 的 `external` 操作。壳复核地址、拒绝嵌入用户名密码，在原页面上方按需打开独立的网页容器，显示当前站点并提供交给浏览器的入口。外链页无 Focus 桥接、实例凭据和实例浏览数据。Android 使用单独进程与数据目录，ArkWeb 使用临时浏览上下文。系统返回一次关闭整次外链浏览。入口的跨站登录回跳仍在实例自己的 WebView 中进行，遵守该条目的 SSO 选择。
- 系统界面、原生抽屉及外链页优先处理返回。在活动的 Focus 根文档，壳核对当前 ticket 后调用 `__focusBack()`。Web 同步报告是否接手，一次只处理最上层。文件预览调用已有的上一文件或取消动作，首个文件关闭后回到对话。根页面报告已到对话顶层时，首次返回打开本地实例抽屉。从这次打开起 2 秒内再次返回，App 退到后台并保留所选实例。超过 2 秒再返回只关闭抽屉。手动打开抽屉时，返回始终回到原实例。离开前台会取消连续返回的计时。缺少协商回调时优先退网页历史，到顶层后采用同一抽屉行为。文档已换、切换实例和不确定的异步回执不能触发第二次后退。普通浏览器继续使用自身导航。
- 在 Android 上，从抽屉面板内向其所在的屏幕边缘横拖，面板跟随手指移动。拖过面板宽度的三分之一或快速朝该边缘甩动，松手即收起。缓慢短拖后松手会回弹。实例列表保留纵向滚动，从实例行上起手横拖会取消该行的点选。点面板外的遮罩也会立即收起抽屉。即使处于连续两次系统返回的 2 秒窗口内，滑动收起或点遮罩都会直接回到当前对话。

顶层导航和销毁撤销 ticket。暂存的页面在未选中期间不能使用 ticket，重新选中同一文档才恢复。外部网页和沙箱 HTML 预览均不获得桥接。
外链地址仅供独立容器浏览。协议不接受任意带凭据的请求、目标路径、代码或业务重发。推送登记和通知权限需要另行协商。

## 实例抽屉和 Android 分发

协商 `drawer` 的宿主接受 `instances` 的明暗主题提示，使用本地注册表覆盖显示实例抽屉。打开、取消、选择当前项均保持当前文档活动。切换到另一项时才执行停放和确认。在普通与阅读顶栏使用独立入口。从对话进入管理后，「返回对话」和系统返回键均可重新选中原实例。纯改名保留原文档；更换地址或删除原实例后回到列表选择。网页只获得所选实例的名字。原生的「切换实例」打开同一抽屉。

Android 宿主另提供 `android-update`。用户在抽屉选「关于 Focus Mobile」时触发可取消事件 `focus-host-about`。顶层文档使用 ticket 请求 `apk-info` 获取已安装版本和摘要；`apk-begin` 提交已选清单，`apk-write` 每块至多 24 KiB，`apk-finish` 验证完整性、包名、版本和当前证书或有效轮换链，再由用户确认交给系统安装器。`apk-abort` 或页面离开清理临时传输。`apk-save` 对已接收的 APK 执行相同校验，经系统选择器另存文件供手动安装。

发布方为明确指定的 Android 渠道发包。源码集成与服务端 stable Release 各自独立。移动分发 Git 仓库的 main 分支在同一提交中包含 `channels/{main|stable}.json` 和 `android/<sha256>.apk`。清单字段为包名 package、版本 version、Android version_code、40 位源码 source_revision、sha256、certificate_sha256 和 size（最多 32 MiB）。APK 内嵌精确源码 revision。发布工具核对 APK 与预期发布证书、版本和源码，远端推送后从独立 Git 对象库读回验签。晋级可复用同一包，普通提交或 CI 不移动渠道。直装版本号可相等；回切还要求安装器允许覆盖及应用数据兼容。

服务端读取独立的 `FOCUS_MOBILE_DIST_URL`（HTTPS 或 SSH Git URL），默认 `https://github.com/ZichaoLong/focus-mobile-dist.git`。已认证、带 CSRF 和文档身份的 `POST /api/mobile/android/{channel}/check` 接受空对象，按需同步，返回 release、checked_at、stale。未发布渠道返回空 release。网络中断时标记最后成功缓存；不将损坏内容提升为当前版本。缓存按发布源隔离在 Focus 数据目录的 mobile-updates 下，独立于服务端安装事务。已认证的 `GET /api/mobile/android/apk/{digest}` 从该源返回确切缓存文件。手机端不向 Git 源发请求；向安装器只授予私有缓存中已校验 APK 的临时读权限。签名密钥属于发布端。

同一发布源同时只允许一项检查。每次拉取在独立目录中运行，成功后才复用其中的 Git 数据。拉取超时或服务进程中断后，可以再次点击「检查客户端更新」。旧版遗留的 Git 锁也不会阻塞重试。检查期间仍可下载上次校验过的 APK。

临时目录用完即删除，中断遗留的目录在下次检查时回收。服务端按分发仓库的提交清理浅克隆中已经用不到的 Git 对象，同一提交只需整理一次。旧版 Git 缓存闲置满七天后也在检查时回收。每个发布源保留本机已检查的 `main` 和 `stable` 渠道当前指向的 APK。安装包被替换或撤回后仍可按摘要下载七天。之后的检查会清理过期包，包括发布源离线或渠道已撤回时的检查。

## 批量管理服务端

「管理实例 → 服务端更新」由壳内置的本地页面汇总实例。每次请求仅打开一个短时管理文档 `/focus-update.html`，与该入口共用网页配置。独立管理文档使用专用 client hint，在同源注册后仅调用更新 API，处理完回收。它没有宿主桥接和业务 WebSocket。只在受限探针上响应已保存且匹配的 Basic 挑战，网页登录或新授权回到具体实例办理。旧服务端可从实例设置先升级。

「检查并准备全部」读取所有入口的安装标识。「检查并准备所选」只读取勾选「检查」的入口，包括待检查和上次检查失败的入口。两种方式都按安装标识合并别名，每套选中的安装只查询一次所选渠道。检查范围与「更新」勾选独立，用户确认后按顺序提交勾选安装的确切 ready 操作。

服务暂时不可达时保留记录，独立安装可以继续。退后台、退出或重启后，已提交任务由服务端继续。重新进入汇总页只核验已记录的操作，尚未提交的安装需要重新确认。记录按本地入口保存，删除入口或更换地址时清理。[服务端更新合同](./focus-web-update.zh-CN.md#多安装批量更新)

## 本机离线记录

Android 和 ArkWeb 通过宿主能力 `records-v1` 协商此功能。用户在「管理实例 → 本机离线记录」按入口启用自动保存。普通浏览器继续使用现有转录窗口、草稿和阅读设置。首次启用只同步用户正在浏览的线程。已停放的页面、后台及断线期间停止读取历史。

- 已选中的 Focus 根文档沿当前会话、document、选中线程和后端代际的读屏障获取 `GET /api/threads/{thread_id}/mobile-records`。v1 返回完整用户和助手文字、工具或分隔符标记、时间窗口内的 observation 和当前请求的翻页线索。落盘按入口 UUID、准确 origin、授权范围、线程分区。注册时协商的不透明范围标识只可用于相等性比较。Focus 会话续期保留范围，换发会话产生新的范围。
- 新到旧逐页归并。可见推理、其他语义行、非空回复及轮次变更分隔工具组。每组保存版本、轮次、首末稳定项、数量和有序成员 SHA-256 链。分页边沿只携带一个未闭合组。展开时复用现存的工具行或沿经过验证的首项读取在线页，逐项核验保存的前缀。原 80 条后追加 3 条时原组可展开已核验的 80 条，新一版记录可显示 83 条。单条详情只在点开后加载到内存。变更、回滚、旧协议无法精确定位均有独立退路。
- App 私有 SQLite 通过两个平台共用的预定义参数化语句提交每一批。已发布的完整版本保留至替代版本完成。线程尾、运行代际及该线程的 observation 必须覆盖到达开头的同一次读取，才能标记完整。中断后只在读取依据和首屏摘要仍匹配时从稳定项恢复。上游游标仅随在线请求传递。持续变动、大消息、空间不足或中断时可保留片段及最近一次完整版本。
- 正文预算为每线程版本 16 MiB、每实例 64 MiB、本机共 192 MiB，包含正在构建的版本。另限制每实例 1000 个、本机 5000 个线程。数据库索引和系统页分配另计。磁盘异常仅影响保存。原生包内的阅读器无网络访问，使用纯文本 DOM 和轻量 Markdown。HTML、图片、公式或图表源文本均不可获得系统桥接或实例会话。
- Android 的普通会话将已接收的消息页异步保存到同一实例、授权、预算和清理边界。打开已保存的线程时优先显示本机阅读位置附近的一页。冷启动由包内的聊天组件独立读取，实例认证和在线页面同时启动。在线就绪后在原线程接续，实时内容沿服务端代际、版本和消息标识合并。上翻先读本机，遇到缺页才用稳定消息位置取得新的在线页。已收到的写入可以在线程切走后完成，清理、锁定和换授权使旧写入失效。没有点开过的线程不预取。
- Android 1.11 与实例 Web 协商 `conversation-layout`。本机首屏与在线页共用会话栏、消息排版和字体。普通模式为输入区保留位置，阅读模式收起输入区。本机首屏只读，在线页接管后恢复草稿和输入。主题、强调色、字号和语言按实例保存，线程的显示布局与其离线副本一同清理。旧副本可先按默认布局打开，再次在线访问会记住对应布局。
- 手机顶栏延迟显示「正在连接」，系统断网或实例不可达时显示相应状态。点会话标题可选择已保存线程或「查看离线副本」。滚动和使用会话选择器期间继续显示本机聊天。在线页绘好后，按最后阅读的消息、段落和屏内偏移接续；停在末尾时可看到新到的消息。
- Android 的前台历史收集可复用普通聊天已接收的最新页和同一次服务端读取的 observation，只在空闲时继续核验和补历史。完整历史、首屏可读和实时连接分别推进。保留的页面直接恢复。缺少本机可读消息时显示加载和重试。ArkWeb 冷启动等待目标页绘好。网络暂不可用时可主动点「查看离线副本」。只有用户主动打开时才创建阅读器；重连与在线更新在读本机副本期间继续，手动返回在线对话。离线点击只有计数的工具组会显示等待，连接恢复后自动展开核对成功的摘要。切换线程、折叠或关闭会撤销展开意图。用户选中另一条本机记录并请求展开时，在线页面可用既有的仅限已打开线程的读取恢复选择。发现线程已关闭或写入结果待核验时由用户处理。
- 网络故障沿用上次确认的授权。已确认要求重新登录时锁住记录，确认撤销、换地址、删除入口或出现不同授权范围时清掉相应旧副本。手工 Basic 登录成功后若无法与已保存的站点、realm 和用户名核对，或经过跨站网页登录后重新获得 Focus 授权，会重新建立该实例的副本。仅遇到网络超时会保留已有副本。共享代理的标签不能证明两个会话属于同一人。旧壳或旧 Web 忽略新能力，旧格式或临时线程缺少可验证的分页源时仍可在线使用。
- 清理页从本机索引列出候选，以实例和可折叠的类别分组。已确认删除、逐 ID 核对后服务端找不到及已归档默认展开并预选。仅关闭、至少 30 天未读、状态待核实与旧版本未区分原因的记录默认收起且不选。当前在读只在全部记录中手动选择。折叠保留选择，组头列出已选数、总数与大小。锁定实例只显示汇总。
- 只在清理页经对应入口的授权配置核对元数据。每批最多 32 个本机线程，只比较同一授权范围，仅获取存在、已归档、找不到或未知。打开列表缺项、超时、旧服务端以及身份无法核对均不足以判定删除。确认前再次检查依据在线归档或缺失而勾选的副本，撤销归档、重新出现或无法复核的条目保留。
- 用户可逐条勾选，或全选当前列表中的所有分组，包括已收起的分组。确认前显示所选数量和大小，若包含当前在读记录则点名提示。清理按实例在本机事务中重新核对所选副本、线程状态、阅读状态和授权，跳过已变化的记录。删除同步清理索引、标题、内容及离线锚点，使旧写入失效。再次主动在线选择该线程或点重新保存可重新收录。停用自动保存保留已存副本。服务端历史、凭据、草稿和结果未知的操作证据使用各自的原有存储。
