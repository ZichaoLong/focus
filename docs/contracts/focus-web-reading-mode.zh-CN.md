# Focus Web 阅读模式

文档角色：中文规范源。英文同步副本：`docs/contracts/focus-web-reading-mode.md`。

## 入口与加载

共享 Web 为最近已确认的线程记住阅读或普通模式与消息位置。普通浏览器使用本标签的 sessionStorage，同标签刷新后可恢复。协商了 `resume` 的移动容器按实例持久保存。
页面访问有效且已选中会话时，只要会话正在加载或已有可阅读内容，桌面会话栏和
窄屏顶栏就提供阅读模式入口。切换会话不应因内容尚未到达而隐藏入口。

在加载期间点击入口立即切换到阅读布局，继续显示该会话的加载状态，并保留退出
和切换会话的操作。内容到达后直接在阅读布局中显示，无需再次点击。
首次连接的加载屏仍可记录本页面的阅读意图，待选中会话可进入阅读模式时兑现。

## 状态边界

- 尚未选中会话的新建页不提供阅读模式入口。
- 切回已记住的线程时恢复该线程的模式。首次打开的线程沿用当前模式。设置中可选择记住最近 5、10 或 20 个线程，默认 10 个，超额时淘汰最久未使用的一项。加载期间暂时没有内容不构成退出条件。
- 同一页面身份仍有效时，前台恢复检查和断线重连不退出阅读模式、不清空草稿。正文同步期间保持模式，
  并重新验证当前阅读锚点。页面重建时须先确认线程且目标正在加载或已有可读内容，才恢复该线程的模式。用户主动退出记为普通模式。
- 加载完毕且没有内容时回到普通模式，不留下空白阅读页。
- 打开新建页、请求显示输入框或失去页面访问权限时退出阅读模式。
- 用户可在加载期间主动退出，内容到达后不得再次自动进入。

线程书签只含模式、可验证的消息与分块标识和偏移。每次切线程由服务端确认目标。有精确锚点的分页正文首读直接定位该条目，已跟随最新时首读最新页。服务端确认条目消失时清除旧锚点并读取最新页；网络失败保留锚点。旧格式在已返回内容中按源行恢复。书签损坏或存储不可用时仍可打开对话。关闭浏览器标签、删除 App 实例或清理相应站点数据会结束对应存储的生命周期。

`web/src/focus/FocusApp.vue` 持有入口条件，`web/src/focus/focusReadingMode.ts`
持有页面展示状态及初次连接的待处理阅读意图；会话选择与加载仍由现有客户端负责。

## 阅读工具栏

宽屏和窄屏的阅读工具栏均提供退出、会话切换、Prompt 历史、可用的导出、运行详情
和设置入口。窄屏按此顺序排列，宽屏保留原来的反向排列。工具栏保持单行，图标按钮
保持 30px；会话标题按剩余空间收缩，过长时省略，不挤压图标按钮或使页面横向溢出。

运行详情使用现有的信息图标与运行状态圆点，设置使用齿轮图标。两者复用现有详情
与设置面板；打开时关闭导出菜单和会话切换器，并收起另一面板。打开或关闭这些面板
不退出阅读模式、不重建会话正文，也不主动改变阅读位置；关闭后继续阅读。

普通模式和阅读模式共用“运行详情 → 当前目标”入口，顶栏不增加目标按钮，输入框上方
不再常驻目标条。运行详情面板默认显示“运行信息”，可切换到“当前目标”；后者直接展开
完整目标，正文独立滚动，状态、用量、预算与操作区保持可见，没有目标时显示空状态。
桌面沿用右侧面板，窄屏沿用全屏详情。目标状态和控制权限仍由现有客户端投影提供，
按钮复用既有暂停、继续、取消流程，取消仍需确认，操作期间禁用按钮，失败信息在详情中
可见。仅“继续”沿用原有的回到最新并恢复跟随行为，查看、暂停或取消不主动改变阅读位置。

## 视口校准、合成与诊断

`web/src/focus/focusViewport.ts` 统一持有固定页面的可视高度和顶部偏移。每次进入或
退出阅读模式，在 DOM 更新后、下一动画帧及一次短延迟后重新读取并同步视口尺寸，
覆盖隐藏顶栏、输入框及手机浏览器界面动画造成的尺寸变化。校准不重建会话组件，
不写入正文滚动位置或草稿，也不持续轮询。快速切换和卸载取消过期回调。
零值、负数及非有限的视口高度不能覆盖有效页面高度；依次回退到窗口、文档高度，
均无效时保留原尺寸。页面恢复可见或从浏览器缓存恢复时也重新同步。

窄屏阅读状态使用独立的合成层，使进入该状态时更新固定页面的合成表面；退出或
切换到宽屏后取消。该兼容处理针对 ArkWeb 真机报告的“布局尺寸、位置与可见样式
正常，但二次进入白屏、旋转后恢复”现象，不依赖浏览器标识，不改变布局尺寸、
重建正文或写入滚动位置。

“运行详情 → 运行信息 → 页面布局诊断”默认关闭采集；展开面板不会自动开启。点击“开始记录”
才测量布局并生成诊断，关闭详情面板后仍继续记录，以便复现问题。“停止记录”立即
停止后续采样并保留结果供复制或下载；再次开始清空旧记录。开关只属于当前文档，刷新后
恢复关闭并清空记录。关闭采集时不读取诊断布局节点、样式或命中位置，不构建诊断
快照；必要的视口同步和阅读模式合成处理独立运行。

面板说明本功能用于页面布局与视口问题，包括白屏、错位，以及切回标签页、正文滚动、
阅读模式、横竖屏或键盘变化后的显示异常；不采集网络请求、程序报错或聊天正文。界面明确区分尚未开始、
正在记录和已停止保留结果，已有结果时开始按钮显示“重新开始记录”。采样由阅读模式
与视口变化、文档可见性变化和正文滚动触发，不是一次性检测或持续轮询。
即使视口尺寸未变，标签页隐藏、恢复可见及恢复后的下一帧也分别采样。
正文滚动按动画帧合并，后台不调度滚动采样；停止记录或卸载会取消待执行采样。

诊断可复制或下载本页的浏览器标识、开始记录时的尺寸、最近六次模式切换
及最近六次视口变化，以及最近六条可见性采样和六条正文滚动采样。
四类记录分别限额，新事件替换同类最旧事件，开始时的快照保留；
旋转屏幕不会挤掉模式切换证据。记录只含
固定布局节点（含文档根与挂载根）的尺寸、滚动量、可见及合成相关样式、焦点标签、
时间，以及工具栏和正文中心点的命中标签、是否仍命中预期区域及是否被对话框覆盖。
`focus-viewport-v3` 还分别统计正文行、Markdown 分块、渲染容器和库内节点占位的
总数、视口内数量、有子元素及空节点数量、最大空节点高度；视口按正文与浏览器可视
区域的交集判断。有子元素只说明 DOM 挂载状态，不能证明节点内容已正确绘制。
不记录命中节点的文本、属性或选择器，不含会话内容、草稿、URL 或鉴权信息；只存在
当前文档内存中，刷新后清除，不自动上传。
“下载 JSON”保存点击时与复制内容一致的完整快照，文件名带时间戳；尚无记录时禁用。
复制和下载不改变采集开关，继续记录不会修改已生成的文件。无法启动下载时显示失败
提示，用户可继续复制结果。
为保留白板状态，复现后宜先停止记录并下载，再点击“最新消息”或刷新恢复页面。
这些测量用于区分尺寸和布局问题，不能单独证明浏览器已经正确绘制像素。手机白屏
回归需按“普通 → 阅读 → 普通 → 阅读”在受影响的真机确认，不能只以桌面模拟
结果判定成功。

## 导出

宽屏和窄屏的 `ReadingModeControls.vue` 均提供当前会话的导出菜单：既有 `export`
capability 可用时显示问答 Markdown 与「打印预览」；当前会话还采用 paginated
历史时显示线程 JSONL。没有会话或没有可用导出能力时隐藏入口，加载会话或读取导出内容时
禁用入口；整个命名及保存过程仍由现有导出互斥控制。切换会话、能力改变、打开会话切换器、切换屏幕布局或退出阅读模式时关闭菜单；
点击菜单外部、移出键盘焦点或 Escape 也可收起，Escape 将焦点返回导出按钮。

导出只发出当前会话的格式选择事件，由 `FocusApp.vue` 转交现有 `FocusThreadActions.vue`
流程，不退出阅读模式，不从当前阅读窗口或聊天 DOM 截取内容。命名、独立文档标题、
系统另存为与兼容下载遵循[导出文件名合同](focus-web-export-filenames.zh-CN.md)，PDF
遵循[问答打印合同](focus-web-summary-print.zh-CN.md)。会话切换列表仍只用于阅读导航。

用户主动操作触发的短暂提示由 `FocusTransientNotice.vue` 持有显示和自动清理，阅读模式
也可见。导出读取失败必须显示失败提示；提示位于阅读工具栏下方且不拦截点击，不恢复
普通模式的常驻告警栏。

性能与连接诊断同样默认关闭；手动采集时追加最多 64 条数值记录，涵盖正文加载耗时、事件字节、断开 code、缓冲溢出和可用时的 long task。停止后冻结，重新开始清空；不采集正文、线程标识、URL 或原始断开原因。具体预算见[有界正文窗口合同](./focus-web-transcript-window.zh-CN.md)。

问答 Markdown 与打印的范围选择统一遵循[问答导出范围合同](focus-web-summary-export.zh-CN.md)，包括最后一轮与跨页勾选轮次。
