# Focus Web 阅读模式

文档角色：中文规范源。英文同步副本：`docs/contracts/focus-web-reading-mode.md`。

## 入口与加载

阅读模式是当前浏览器页面的展示状态，不写入会话或持久化偏好。
页面访问有效且已选中会话时，只要会话正在加载或已有可阅读内容，桌面会话栏和
窄屏顶栏就提供阅读模式入口。切换会话不应因内容尚未到达而隐藏入口。

在加载期间点击入口立即切换到阅读布局，继续显示该会话的加载状态，并保留退出
和切换会话的操作。内容到达后直接在阅读布局中显示，无需再次点击。
首次连接的加载屏仍可记录本页面的阅读意图，待选中会话可进入阅读模式时兑现。

## 状态边界

- 尚未选中会话的新建页不提供阅读模式入口。
- 阅读模式可跨会话切换保留；加载期间暂时没有内容不构成退出条件。
- 加载完毕且没有内容时回到普通模式，不留下空白阅读页。
- 打开新建页、请求显示输入框或失去页面访问权限时退出阅读模式。
- 用户可在加载期间主动退出，内容到达后不得再次自动进入。

`web/src/focus/FocusApp.vue` 持有入口条件，`web/src/focus/focusReadingMode.ts`
持有页面展示状态及初次连接的待处理阅读意图；会话选择与加载仍由现有客户端负责。

## 视口校准、合成与诊断

`web/src/focus/focusViewport.ts` 统一持有固定页面的可视高度和顶部偏移。每次进入或
退出阅读模式，在 DOM 更新后、下一动画帧及一次短延迟后重新读取并同步视口尺寸，
覆盖隐藏顶栏、输入框及手机浏览器界面动画造成的尺寸变化。校准不重建会话组件，
不写入正文滚动位置或草稿，也不持续轮询。快速切换和卸载取消过期回调。
零值、负数及非有限的视口高度不能覆盖有效页面高度；依次回退到窗口、文档高度，
均无效时保留原尺寸。页面恢复可见或从浏览器缓存恢复时也重新同步。

窄屏阅读状态使用独立的合成层，使进入该状态时更新固定页面的合成表面；退出或
切换到宽屏后取消。该兼容处理针对 ArkWeb 真机报告的“布局尺寸、位置与可见样式
正常，但二次进入白屏、旋转后恢复”现象，不依赖浏览器标识，不改变布局尺寸、
重建正文或写入滚动位置。

“运行详情 → 页面布局诊断”默认关闭采集；展开面板不会自动开启。点击“开始记录”
才测量布局并生成诊断，关闭详情面板后仍继续记录，以便复现问题。“停止记录”立即
停止后续采样并保留结果供复制；再次开始清空旧记录。开关只属于当前文档，刷新后
恢复关闭并清空记录。关闭采集时不读取诊断布局节点、样式或命中位置，不构建诊断
快照；必要的视口同步和阅读模式合成处理独立运行。

诊断可复制本页的浏览器标识、开始记录时的尺寸、最近六次模式切换
及最近六次视口变化。两类记录分别限额，旋转屏幕不会挤掉模式切换证据。记录只含
固定布局节点（含文档根与挂载根）的尺寸、滚动量、可见及合成相关样式、焦点标签、
时间，以及工具栏和正文中心点的命中标签、是否仍命中预期区域及是否被对话框覆盖。
不记录命中节点的文本、属性或选择器，不含会话内容、草稿、URL 或鉴权信息；只存在
当前文档内存中，刷新后清除，不自动上传。
这些测量用于区分尺寸和布局问题，不能单独证明浏览器已经正确绘制像素。手机白屏
回归需按“普通 → 阅读 → 普通 → 阅读”在受影响的真机确认，不能只以桌面模拟
结果判定成功。

## 导出

宽屏和窄屏的 `ReadingModeControls.vue` 均提供当前会话的导出菜单：既有 `export`
capability 可用时显示问答 Markdown 与打印／另存为 PDF；当前会话还采用 paginated
历史时显示线程 JSONL。没有会话或没有可用导出能力时隐藏入口，加载会话或读取导出内容时
禁用入口；整个命名及保存过程仍由现有导出互斥控制。切换会话、能力改变、打开会话切换器、切换屏幕布局或退出阅读模式时关闭菜单；
点击菜单外部、移出键盘焦点或 Escape 也可收起，Escape 将焦点返回导出按钮。

导出只发出当前会话的格式选择事件，由 `FocusApp.vue` 转交现有 `FocusThreadActions.vue`
流程，不退出阅读模式，不从当前阅读窗口或聊天 DOM 截取内容。命名、独立文档标题、
系统另存为与兼容下载遵循[导出文件名合同](focus-web-export-filenames.zh-CN.md)，PDF
遵循[问答打印合同](focus-web-summary-print.zh-CN.md)。会话切换列表仍只用于阅读导航。

用户主动操作触发的短暂提示由 `FocusTransientNotice.vue` 持有显示和自动清理，阅读模式
也可见。导出读取失败必须显示失败提示；提示位于阅读工具栏下方且不拦截点击，不恢复
普通模式的常驻告警栏。
