# Focus Web 问答打印与 PDF 保存合同

文档角色：中文规范源。英文同步副本：`docs/contracts/focus-web-summary-print.md`。

## 范围与入口

桌面会话菜单、侧栏会话菜单、窄屏顶部导出菜单、窄屏会话切换菜单和各屏幕尺寸下的阅读模式导出菜单，在既有
`export` capability 可用时，同时提供“导出问答 Markdown”和“保存 PDF 或打印”。
打印操作与 Markdown、线程数据导出共用正在导出的互斥状态。
文件名输入框与 PDF 默认建议名遵循[导出文件名合同](focus-web-export-filenames.zh-CN.md)。

`createFocusThreadActions` 先显示[导出范围](focus-web-summary-export.zh-CN.md)与标题选项，再通过 authenticated `exportThreadSummary` 取得选定范围的完整
Markdown；内容与边界由 [Web wire 合同](focus-web-wire.zh-CN.md) 的
`POST /api/threads/{thread_id}/export-summary` 定义。不得从聊天 DOM、已加载窗口或
阅读模式截取导出内容，也不得改变问答导出对工具过程、reasoning 和非文本附件的排除。
PDF 消费者不新增 PDF endpoint、服务端浏览器依赖、外部转换服务或 PDF 专用 wire DTO。

## 完整性与渲染

`SummaryPrintApp.vue` 是独立打印文档；`summaryPrintMarkdown.ts` 负责静态渲染，
`summaryPrintPreparation.ts` 负责图示、图片和字体准备。预览必须呈现整份导出，不使用
聊天虚拟化、渐进批次、代码折叠或 diff 头尾截取。代码保留全部行并允许换行和跨页；
表格允许单元格换行、跨页并重复表头。原生打印布局隐藏界面控件和使用说明。

文档标题与文件名独立。预览提供标题输入框，仅替换导出器生成的首个一级标题；用户输入按纯文本显示。
编辑标题立即更新打印正文，不重新渲染问答或重新加载图片、公式、图示；打印时隐藏输入框。
顶层渲染失败仍保留规范化标题与完整问答源码。

中文标点附近的加粗识别与粗体字体回退复用[正文渲染合同](focus-web-markdown-rendering.zh-CN.md)。

- 公式复用 `markdownMath.ts` 的 exact grammar：同一行闭合的 `\(...\)`，块位置的
  `\[...\]` 或 `$$...$$`。不猜测单美元、未闭合或正文中的块公式。未识别内容按
  文字保留，KaTeX 失败时保留含定界符的源码。KaTeX 禁止 trusted HTML/URL 扩展。
- Markdown 原生 HTML 不执行。代码与失败源码必须转义；Markdown 链接沿用解析器的
  安全 URL 校验。图片只尝试 HTTP(S) 或内嵌常见栅格格式，不读取本机路径或为图片
  额外附加 Focus 认证请求头；受站点 CSP 限制或加载失败时显示其 Markdown 地址与替代文字。
- Mermaid 使用已有依赖的 strict 模式并清洗 SVG；失败时保留完整围栏内容。
- 图片与字体有有界等待，准备失败须保留源码或地址并提示用户检查预览；顶层解析或
  准备异常回退整份原始 Markdown。完整导出读取失败时显示失败状态，不启用打印按钮。

## 直接保存 PDF

预览就绪后，「直接保存 PDF」从同一份完整正文和当前文档标题在客户端生成 A4 PDF。浏览器使用共享文件选择器或下载，移动宿主使用已有的 `save` 文件协议。用户点击时先选择目标，取消选择即可继续阅读预览。保存过程中禁止重复提交，关闭预览释放本次导出的 worker 和暂存文件。文件写入结束或交给下载流程时分别显示状态。

共享 Web 按需从实例加载排版 worker、WebAssembly 和文档实际使用的字体子集。中文正文可选取和搜索，代码可以跨页，跨页表格重复表头。公式和 Mermaid 图示沿用已准备好的预览图形，图片采用预览已读取的像素。图形转换失败时保留源码或地址并提示。缺少字形时保留 PDF 并提示核对占位符。桌面和移动端共用这条路径，Linux 服务只提供原有问答导出与静态文件。

## 打印与生命周期

协商移动宿主 `save` 或 `print` 能力时，Web 在当前 document 内存中把同一份完整导出交给 `SummaryPrintApp`。预览独占可见页面和打印布局，支持 `print` 时，「系统打印」使用原生网页容器的打印适配器。关闭预览或系统返回均回到原线程。刷新后须重新导出。[移动宿主合同](focus-mobile.zh-CN.md)

移动预览的「打印诊断」默认关闭。用户开始后，当前预览在内存中记录 App 和引擎报告的版本、打印按钮点击、宿主桥接回执、宿主前后台信号和页面可见性、焦点变化。报告保留最近 40 条带相对时间的事件、点击总数和被替换的事件数。宿主回执和可见性只描述各自的观察，面板显示及文件保存须由用户确认。

手动停止、复制、保存或五分钟超时结束采集。复制和保存先冻结同一份 JSON，供用户检查、复制或通过已协商的系统文件选择器保存。重新开始替换旧记录，关闭或刷新预览清空记录。报告仅含预定义字段和事件，不收集正文、标题、文件名、URL、凭据、原始异常或未识别的宿主返回文本，也不上传。

宿主协商 `print-diagnostics` 且用户开始记录后，预览提供「打印一页测试文本」。停止时，同一报告的 `native` 字段按点击编号区分会话和原生测试页，包含宿主回执和系统对适配器的开始、排版、写出、结束调用。Web 和原生各自用相对时间，跨端按编号关联。回调代表系统发起了该步骤，用户看到面板和实际保存 PDF 分别确认。原生记录失效时报告标为不可用。仅协商 `print` 的宿主沿用原有网页诊断。

协商 `print-job-diagnostics` 后，预览提示在最后一次点击后等约 35 秒再复制。`native.observations` 单独汇总系统界面启动调用、Focus 窗口与 Activity 变化及同一任务的定时状态。每条记录有原生相对时间、点击编号和来源。`job-not-listed` 表示该次查询没有列出本次任务，最终结果仍需其他证据确认。扩展数据缺失或格式无效时，报告保留已有的适配器回调。

`summaryPrintWindow.ts` 在范围弹窗的确认点击内同步打开同源 `?print=summary` 页面，以避免
异步读取后才打开窗口造成拦截。弹窗被拦截时提示允许本站弹窗再重试，保留范围选项，并不启动导出。
预览只接收 exact opener、origin 和一次性 rendezvous ID 匹配的内容；发送方也校验
exact child、origin 与 ID。内容只在内存传递，不写入 URL、localStorage 或服务端文件。
页面 URL 不携带会话正文或认证参数。传递成功后移除监听并断开 opener；关闭、超时
或读取失败有明确清理/失败路径。刷新、独立打开或分享预览 URL 不恢复内容。

打印入口不会挂载 `FocusApp` 或注册第二个 active document。预览取得内容前应保留原
标签页，取得后可以独立预览并反复打印。只有渲染和资源准备完毕才启用打印按钮。

浏览器的「系统打印」按钮调用原生 `window.print()`，浏览器决定打印、保存 PDF、纸张、缩放和页眉页脚。
不得把函数返回或 `afterprint` 当作文件已保存的证据；取消后可再次打印。页面提供
桌面“另存为 PDF”、Android Chrome“分享 → 打印”与 iPhone Safari“分享 → 标记”
的使用提示。实际菜单随系统和浏览器版本变化，不承诺手机浏览器都支持一键下载。
宽表格、超长公式可由用户调整横向纸张或缩放；不同字体和浏览器不保证像素一致。

## 验证边界

单元测试验证完整代码、公式语法与回退、安全转义、完整导出调用、弹窗拦截、互斥、
同源传递与失败清理。浏览器验证覆盖宽/窄屏菜单、独立预览、实际 PDF 的分页与文本、
取消后重试、Markdown 下载和导出失败。桌面 Chromium 与窄屏模拟不能替代真机 Safari、
Android Chrome 的系统保存流程验证。
