# Focus Web 问答打印与 PDF 保存合同

文档角色：中文规范源。英文同步副本：`docs/contracts/focus-web-summary-print.md`。

## 范围与入口

桌面会话菜单、侧栏会话菜单、窄屏顶部导出菜单、窄屏会话切换菜单和各屏幕尺寸下的阅读模式导出菜单，在既有
`export` capability 可用时，同时提供「导出问答 Markdown」和「打印或保存 PDF」。选定轮次和内容后点「打开预览」，进入「打印预览」页。
打印操作与 Markdown、线程数据导出共用正在导出的互斥状态。
文件名输入框与 PDF 默认建议名遵循[导出文件名合同](focus-web-export-filenames.zh-CN.md)。

`createFocusThreadActions` 先显示[导出范围](focus-web-summary-export.zh-CN.md)与标题选项，再通过 authenticated `exportThreadSummary` 取得选定范围的完整
Markdown；内容与边界由 [Web wire 合同](focus-web-wire.zh-CN.md) 的
`POST /api/threads/{thread_id}/export-summary` 定义。不得从聊天 DOM、已加载窗口或
阅读模式截取导出内容，也不得改变问答导出对工具过程、reasoning 和非文本附件的排除。
打印预览请求可取得限时的服务端快照标识，普通 Markdown 导出按原接口返回。

## 完整性与渲染

`SummaryPrintApp.vue` 是独立打印文档；`summaryPrintMarkdown.ts` 负责静态渲染，
`summaryPrintPreparation.ts` 负责图示、图片和字体准备。预览必须呈现整份导出，不使用
聊天虚拟化、渐进批次、代码折叠或 diff 头尾截取。代码保留全部行并允许换行和跨页；
表格允许单元格换行、跨页并重复表头。原生打印布局隐藏界面控件和使用说明。

文档标题与文件名独立。预览提供标题输入框，仅替换导出器生成的首个一级标题；用户输入按纯文本显示。
编辑标题立即更新打印正文，不重新渲染问答或重新加载图片、公式、图示；打印时隐藏输入框。
顶层渲染失败仍保留规范化标题与完整问答源码。

中文标点附近的加粗识别与粗体字体回退复用[正文渲染合同](focus-web-markdown-rendering.zh-CN.md)。

- 公式复用 `markdownMath.ts` 的 exact grammar：同一行闭合的 `\(...\)`，块位置的
  `\[...\]` 或 `$$...$$`。不猜测单美元、未闭合或正文中的块公式。未识别内容按
  文字保留，KaTeX 失败时保留含定界符的源码。KaTeX 禁止 trusted HTML/URL 扩展。
- Markdown 原生 HTML 不执行。代码与失败源码必须转义；Markdown 链接沿用解析器的
  安全 URL 校验。图片只尝试 HTTP(S) 或内嵌常见栅格格式，不读取本机路径或为图片
  额外附加 Focus 认证请求头；受站点 CSP 限制或加载失败时显示其 Markdown 地址与替代文字。
- Mermaid 使用已有依赖的 strict 模式并清洗 SVG；失败时保留完整围栏内容。
- 图片与字体有有界等待，准备失败须保留源码或地址并提示用户检查预览；顶层解析或
  准备异常回退整份原始 Markdown。完整导出读取失败时显示失败状态，不启用打印按钮。

## 服务端 PDF 下载

用户在预览中选择下载 PDF 并确认保存位置后，创建服务端任务。任务使用当前会话获准读取的原始 Markdown 快照、同一批轮次和已编辑的纯文本标题。服务端依次尝试本机已安装的 Chromium 系浏览器和 Focus 自带的排版器。浏览器缺失、启动失败或超过 25 秒时自动使用内置排版。两条路径使用安装时交付的字体、公式资源和打印样式。生成文件时无需访问外网。准备 main 沿用现有构建与 Python 锁定依赖安装流程，浏览器可用性在导出时检测。

内置排版嵌入中文、数学符号和公式图形，长代码可跨页，过宽的表按字段展开。服务器只嵌入文档内的可用图片，其他图片保留文字或地址。无法排版的公式、图示保留源码，已检测出的字形缺失标明 Unicode 编码。富文本排版失败时尝试整份原文。结果显示实际引擎、检测到的问题及可定位的轮次。系统资源耗尽、超时或写入失败会显示错误。

同一安装的数据根下同时排版一份。快照有效一小时，完成文件有效十五分钟，缓存还受数量和空间上限约束。创建、查询和下载按同一会话与快照校验，创建要求同源与 CSRF。相同任务标识的重试沿用第一次提交。短时断线后可继续查询同一任务。排队、公式数量、分页、传输及经过时间分别显示。系统目标写入完成或普通浏览器接手下载时给出相应提示。

## 打印与生命周期

「打印」调用浏览器的系统打印接口或移动端当前 WebView 的原生打印适配器。系统明确拒绝时立即显示原因。收到回执后，若预览仍在前台且约三秒内未观察到面板切换，提示当前客户端环境可能不支持系统打印。本次预览支持下载时，同时提供「试试下载 PDF」。观察到面板切换并返回后，可用的下载入口显示为「下载 PDF」。用户可以重试打印。取消打印后保留选区、预览和标题，文件是否保存以实际写入结果为准。移动端关闭预览或系统返回均回到原线程。[移动宿主合同](focus-mobile.zh-CN.md)

普通浏览器在范围弹窗的确认手势内打开同源打印页。弹窗被拦截时保留选项供重试。发送与接收双方核对 origin、窗口对象和一次性标识，在内存中交接内容和下载凭据。URL 只含短期交接标识。交接完成后移除监听并断开 opener。预览独立渲染，无需注册第二个活动 document；刷新后须重新导出。

## 验证边界

单元测试验证完整代码、公式语法与回退、安全转义、完整导出调用、弹窗拦截、互斥、
同源传递与失败清理。浏览器验证覆盖宽/窄屏菜单、独立预览、实际 PDF 的分页与文本、
取消后重试、Markdown 下载和导出失败。桌面 Chromium 与窄屏模拟不能替代真机 Safari、
Android Chrome 的系统保存流程验证。
