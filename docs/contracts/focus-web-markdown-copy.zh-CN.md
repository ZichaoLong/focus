# Focus Web Markdown 复制合同

文档角色：中文规范源。英文同步副本：`docs/contracts/focus-web-markdown-copy.md`。

## 范围与内容

浏览器 Markdown 展示为代码块、纯文本围栏块、diff 块、已识别的行内公式与独立公式
提供单独的复制按钮。普通段落与行内代码沿用选中文字复制或整条回答复制。

- 代码与文本块复制完整块内容并保留空白，不包含 Markdown 围栏。长消息使用简化的
  pre 展示或高亮组件回退时仍提供复制按钮。
- diff 块复制完整源内容，包括加减号与展示窗口中省略的行。
- 公式按钮标为“复制 LaTeX”，复制原始公式内部内容，保留空白与反斜杠，不包含
  外层数学定界符；不得从 KaTeX DOM 或经过渲染规范化的文本反推复制内容。

## 公式识别与失败行为

`web/src/lib/markdownMath.ts` 是公式识别入口。复制功能沿用该解析结果，不另设猜测公式的规则。
行内公式使用同一行闭合的 `\(...\)`；独立公式使用处于块位置的 `\[...\]` 或 `$$...$$`。
代码、转义内容、单美元写法、正文位置的块定界符和未闭合内容继续作为文字。

已识别的公式在加载中或渲染失败、显示原文时仍可复制。流式输出中的未闭合公式不提供
公式按钮，闭合并被解析后再提供。普通文字中的疑似公式不自动附加公式按钮。

## 展示与剪贴板

公式与代码块的复制控件由 Markdown 展示层持有；公式按钮可通过键盘和触屏操作，
独立公式的横向滚动不得遮挡按钮。剪贴板写入复用 `web/src/lib/clipboard.ts` 的浏览器
API 与普通 HTTP 回退。新的复制控件仅在成功写入后反馈“已复制”，失败时提示选中文字复制。
复制不改变消息原文、公式解析规则、会话或服务端状态。
